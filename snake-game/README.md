# 贪吃蛇 (Snake)

简单的一个小型游戏（HTML + CSS + JavaScript），直接打开浏览器即可运行。

## 文件
- `index.html` — 页面与画布
- `style.css` — 基础样式
- `script.js` — 游戏逻辑（Canvas）

## 运行方法
1. 直接在文件管理器 / Finder 中双击 `index.html`，使用浏览器打开。

或者使用一个本地服务器（推荐）：

```bash
# 使用 Python 3 内置的简单 HTTP 服务器
cd snake-game
python3 -m http.server 8000
# 然后在浏览器打开 http://localhost:8000
```
## 操作说明
- 使用方向键 或 WASD 控制移动。
- 空格键可以切换 暂停/继续。
- 点击"开始 / 重启" 重新开始游戏。
- 点击"🔒 安全测试" 运行漏洞测试。

## 安全测试功能
新增的漏洞测试功能可以检测以下安全问题：
- **XSS漏洞**: 检测跨站脚本攻击风险
- **输入验证**: 测试输入数据的合法性验证
- **内存泄漏**: 检测内存使用异常
- **状态篡改**: 测试游戏状态是否可被外部修改
- **DoS攻击**: 检测拒绝服务攻击风险
- **跨域问题**: 检测CORS相关安全问题

测试完成后会生成详细的安全报告，显示发现的漏洞及其严重程度。

祝你玩得开心！如果需要我可把游戏扩展为带关卡、移动障碍或多人版本。
